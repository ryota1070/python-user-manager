# Python User Manager

A simple Python CLI app for managing users with file saving.

## Features

- Add users
- Show all users
- Show adult users only
- Validate name, email, age, and country
- Save users to a text file
- Load users from a text file

## Tech Stack

- Python
- Git
- GitHub
- requests

## What I Learned

- How to create and use Python classes
- How to handle errors with try / except
- How to validate user input
- How to save and load data using files
- How to use functions to organize code
- How to use Git and GitHub for version control
